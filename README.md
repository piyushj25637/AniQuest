# 🎌 Anime Explorer Web App

## 📌 Project Description

The Anime Explorer Web App is a web-based application that allows users to search and explore anime using real-time data from the Kitsu API. Users can view anime details such as title, rating, episode count, and poster images in an interactive and user-friendly interface.

This project demonstrates the use of JavaScript for API integration, data handling using higher-order functions, and responsive UI design using CSS.

---

## 🌐 API Used

**Kitsu API**
Base URL: https://kitsu.docs.apiary.io/#

The API provides detailed information about anime, including ratings, images, and episode counts.

---

## ✨ Features

* 🔍 **Search Anime**
  Users can search anime by name using the API.

* 🎯 **Filter Results**
  Filter animes.

* 🔃 **Sort Functionality**

* 📄 **Responsive Card Layout**
  Each anime is shown as a card with image and details.
